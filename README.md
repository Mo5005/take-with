# Take With

Community app that connects **travellers with spare luggage space** to **people who need something carried** on the same route — e.g. 2 kg free on a flight Bremen → Damascus.

**Status:** concept final. Next step: build the test version (web app). App ID: `com.dumo.takewith`.
